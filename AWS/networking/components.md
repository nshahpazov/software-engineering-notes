# This page contains definitions and information about different networking components



1. VPC

2. IGW (AWS Internet Gateway)
3. [ENI (Elastic Network Interface)](https://docs.aws.amazon.com/AWSEC2/latest/UserGuide/using-eni.html) - A virtual network interface that can be attached to an instance in a VPC. It can include attributes such as a primary private IPv4 address, one or more secondary private IPv4 addresses, an Elastic IP address, a MAC address, a source/destination check flag, and more.
4. Subnets

5. AZs

6. Security Groups
7. Load Balancer
8. Target Group
9. Health checks
10. NAT Gateway - A managed NAT service that provides outbound internet access to instances in a private subnet while preventing inbound traffic from the internet.
11. Route Tables
12. DHCP Options Sets
13. VPC Peering
14. Transit Gateway
15. Route 53 - A scalable and highly available Domain Name System (DNS) web service designed to route end-user requests to internet applications hosted in AWS.
